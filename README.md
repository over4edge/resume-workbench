# 简历工作台

本地单文件简历制作/修改工具：多份简历管理、7 套模板、预设+自定义配色、实时预览、AI 导入旧简历、AI 润色，支持导出 **PDF / Word / 图片**。

## 首页

打开应用会先进入一个「Viktor Oddy」风格的全新落地页：纯白背景、衬线大字标题、深色胶囊按钮、无限跑马灯、评价轮播、使用方式卡片、能力展示与鼠标轨迹 CTA。点任意「开始制作」进入工作台；「上传旧简历」可直接进入导入流程。

## v3 大模块系统（教育经历 / 项目经历这类）

- **模块可重命名**：每个大模块标题直接点击输入框修改，预览实时更新（如「教育经历」→「学习经历」）
- **模块可删除 / 恢复**：大模块卡片右上角 🗑 删除；删除后底部出现「＋ 教育经历 / ＋ 项目经历」等按钮可随时加回
- **模块可拖拽排序**：按住大模块卡片左侧 ⋮⋮ 手柄上下拖动，整块模块（含内容）顺序即变，预览同步
- **可添加自定义模块**：底部「＋ 添加自定义模块」新建任意模块（如「音乐制作经历」「荣誉奖项」），条目支持 名称+内容 两栏、可增删、可拖拽
- 7 套模板全部按模块顺序渲染（深蓝商务模板技能模块移入内容区以支持排序）

## v2 编辑器增强

- **多行输入**：项目描述 / 技能内容 / 自我评价均为自动展开的多行输入框，点击聚焦即展开，无需换行烦恼
- **模块折叠**：教育 / 项目 / 技能每条卡片头部「▾」可折叠/展开，长简历更好管理
- **拖拽排序**：拖动每条卡片左侧「⋮⋮」手柄即可调换教育、项目、技能的先后顺序（预览同步更新）
- **历史记录**：每次编辑自动保存快照，「🕘 历史」弹窗可查看并一键恢复到任意版本；快捷键 ⌘/Ctrl+Z 撤销（输入框内为原生文本撤销）
- **智能一页**：预览区顶部实时提示内容是否超出/不足一页，一键「⚡ 智能一页」自动缩放排满
- **导入 JSON**：侧栏「我的简历」下方新增「⬆ 导入 JSON 简历」入口

## 快速开始

**方式一：完整模式（推荐，功能最全）**

```bash
cd "简历工作台"
python3 server.py
```

自动打开浏览器 http://127.0.0.1:8787 。此模式下 AI 导入/润色、Word 导出、PDF 任意字不丢字均可用。

**方式二：离线模式**

直接双击打开 `简历工作台.html`。可编辑、预览、多份管理、JSON 导入导出、导出 PDF（打印）、导出图片；AI 与 Word 导出会提示需要启动本地服务。

> 说明：server.py 仅依赖 Python 标准库（零第三方依赖）；如需“任意生僻字导出 PDF 不丢字”，建议 `pip3 install fonttools`（未安装时自动回退内置常用字字体）。

## AI 配置（DeepSeek）

1. 点击右上角「⚙ 设置」，填入 DeepSeek API Key（sk-...）。
2. 默认模型 `deepseek-chat`、接口 `https://api.deepseek.com`，可自定义 OpenAI 兼容地址。
3. Key 只保存在本机浏览器 localStorage，经本地 server.py 转发到 DeepSeek，不落盘、不上传其他服务器。

**AI 导入**：点「AI 导入 PDF」选择旧简历 PDF，自动提取姓名/教育/项目/技能等，生成后请人工校对（扫描版无文字层暂不支持）。
**AI 润色**：项目描述或自我评价旁的 ✨ 按钮，生成 3 个候选供选择。

## 导出说明

- **PDF**：浏览器打印 → 另存为 PDF → 纸张 A4 → 边距「无」→ 勾选「背景图形」。点「自动排版一页」可让内容无论多少都占满整页（自动调字号/行距/区块间距）。
- **Word**：需启动 server.py；生成标准 .docx（含照片、配色、仅开始时间），可用 Word/WPS 二次编辑。
- **图片**：PNG，2 倍分辨率（≈1588×2246），白底含照片。

## 免费部署到网页（国内可访问）

已内置 `deploy/` 部署包，为国内网络做了适配（无 Google Fonts、pdf.js 已本地化，零境外依赖）：

- **国内推荐**：腾讯云 **EdgeOne Pages**（免费、无需备案、国内秒开）——把 `deploy/index.html` 和 `vendor/` 上传即可，详见 `deploy/README.md`
- **国内 AI 代理**：腾讯云云函数 SCF（免费 40 万次/月），`deploy/worker-scf.py` 即开即用，在「设置 → 远程 AI 代理地址」填入其地址
- 海外备用：Netlify Drop / GitHub Pages / Cloudflare Pages（详见 `deploy/README.md`）
- 纯静态版编辑/模板/配色/证件照/PDF/图片导出全部可用

## 数据与隐私

- 数据全部保存在浏览器 localStorage，无账号、无云存储。
- 单份简历可导出 JSON 备份/迁移（侧栏简历项 ⬇ 按钮），或「导入 JSON」恢复。
- 本地服务仅监听 127.0.0.1，请勿暴露到公网。
